Fonts for the editable PowerPoint (deck.pptx)

PowerPoint shows the deck's fonts only if they are installed on the computer
that opens it. Install every .ttf in this folder first:
  Windows: select all the .ttf files, right-click > Install (or "Install for all users").
  macOS:   double-click each file > Install Font.
Then open deck.pptx. Without them PowerPoint substitutes other fonts and
some text may wrap differently.

Newsreader, Nunito and Fira Code: SIL Open Font License (Google Fonts),
cut into one file per weight. Virgil: the Excalidraw hand-drawn font (OFL).
