    BEFORE opening it, install the fonts in the "fonts" folder:
      Windows: open the fonts folder, select all the .ttf files (Ctrl+A),
               right-click > Install (or "Install for all users").
               Close and reopen PowerPoint afterwards.
      Linux:   mkdir -p ~/.local/share/fonts/team147
               cp fonts/*.ttf ~/.local/share/fonts/team147/
               fc-cache -f
               (then reopen LibreOffice Impress / OnlyOffice)
      macOS:   double-click each file > Install Font
    Without them PowerPoint swaps in other fonts and some text may wrap.
